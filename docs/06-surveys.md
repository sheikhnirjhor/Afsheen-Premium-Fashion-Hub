# 06 - Surveys

## 1. Purpose

This document presents the findings from a customer survey conducted to understand the preferences, expectations, and pain points of Afsheen's target audience regarding online fashion shopping.

## 2. Survey Design

| Parameter | Detail |
|-----------|--------|
| Target Audience | Women aged 18–45, fashion-conscious |
| Sample Size | 55 respondents |
| Distribution | Instagram DMs, WhatsApp, in-store QR code |
| Duration | Week 1–2 |
| Incentive | 10% discount code for completion |
| Questions | 20 (multiple choice, Likert scale, open-ended) |

## 3. Demographics

| Category | Distribution |
|----------|-------------|
| **Age 18–24** | 35% |
| **Age 25–34** | 45% |
| **Age 35–45** | 20% |
| **Urban** | 78% |
| **Semi-Urban** | 22% |
| **Smartphone Primary** | 87% |
| **Desktop/Laptop** | 13% |

## 4. Key Questions & Results

### Q1: How often do you shop for fashion online?
| Response | Percentage |
|----------|-----------|
| Weekly | 15% |
| Monthly | 40% |
| Occasionally (few times a year) | 35% |
| Rarely | 10% |

### Q2: Which device do you primarily use for online shopping?
| Response | Percentage |
|----------|-----------|
| Smartphone | 87% |
| Laptop/Desktop | 10% |
| Tablet | 3% |

### Q3: What is your preferred payment method?
| Response | Percentage |
|----------|-----------|
| Cash on Delivery | 62% |
| Credit/Debit Card | 18% |
| JazzCash/EasyPaisa | 15% |
| Bank Transfer | 5% |

### Q4: What matters most when shopping for fashion online? (Select top 3)
| Factor | Selection Rate |
|--------|---------------|
| Product quality and images | 92% |
| Reasonable prices | 78% |
| Easy return/exchange policy | 75% |
| Fast delivery | 71% |
| Size guide availability | 68% |
| Customer reviews | 55% |
| Website design and ease of use | 52% |
| Brand reputation | 48% |

### Q5: What stops you from completing an online purchase? (Select all that apply)
| Barrier | Percentage |
|---------|-----------|
| Uncertain about size/fit | 72% |
| Hidden shipping costs | 65% |
| Website looks untrustworthy | 58% |
| Complicated checkout process | 52% |
| Limited payment options | 45% |
| No order tracking | 42% |
| Slow website loading | 38% |

### Q6: How important is a size guide on product pages?
| Response | Percentage |
|----------|-----------|
| Very Important | 68% |
| Somewhat Important | 25% |
| Neutral | 5% |
| Not Important | 2% |

### Q7: Would you use a live chat feature for customer support?
| Response | Percentage |
|----------|-----------|
| Yes, definitely | 55% |
| Maybe | 30% |
| No | 15% |

### Q8: What would make you shop from a new fashion website? (Select top 2)
| Incentive | Selection Rate |
|-----------|---------------|
| First-time buyer discount | 82% |
| Free shipping on first order | 75% |
| Easy return policy | 68% |
| Quality product photos | 65% |
| Customer reviews/testimonials | 52% |

## 5. Satisfaction Benchmarks

| Metric | Target | Industry Avg |
|--------|--------|-------------|
| Page load time | < 3 seconds | 4.2 seconds |
| Checkout steps | ≤ 3 steps | 5.1 steps |
| Customer support response | < 2 minutes | 8 minutes |
| Return policy clarity | 100% visible | 60% |

## 6. Key Takeaways

1. **Mobile-first is non-negotiable** — 87% shop primarily on smartphones
2. **COD is king** — 62% prefer cash on delivery
3. **Size anxiety is real** — 72% abandon carts due to size uncertainty
4. **Trust matters** — 58% abandon if the site looks untrustworthy
5. **Live chat is wanted** — 85% are open to using it
6. **First-time incentives drive adoption** — 82% want a welcome discount

## 8. Limitations

- Sample size of 55 may not be statistically significant for all segments
- Survey distributed primarily through existing channels (may miss new audience)
- Self-selection bias — respondents already interested in fashion
