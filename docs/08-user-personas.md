# 08 - User Personas

## 1. Purpose

User personas represent the key audience segments for Afsheen Premium Fashion Hub. They guide design decisions, feature prioritization, and user experience strategies.

## 2. Persona 1: Ayesha — The Fashion-Forward Student

| Attribute | Detail |
|-----------|--------|
| **Name** | Ayesha Khan |
| **Age** | 22 |
| **Occupation** | University Student |
| **Location** | Lahore, Pakistan |
| **Income** | PKR 30,000/month (part-time + allowance) |
| **Tech Savviness** | High |
| **Device** | iPhone 14, occasional laptop |

### Goals
- Stay trendy without breaking the budget
- Discover new fashion brands before they go mainstream
- Share purchases on social media (Instagram stories)

### Frustrations
- Can't find reliable size information online
- Hidden shipping costs at checkout
- Slow website loading on mobile data

### Behavior
- Browses Instagram fashion pages daily
- Compares prices across 3–4 websites before purchasing
- Prefers mobile shopping during commute
- Reads customer reviews before buying
- Uses Cash on Delivery primarily

### Quote
> "If the website looks cheap, I assume the clothes are cheap too."

## 3. Persona 2: Fatima — The Working Professional

| Attribute | Detail |
|-----------|--------|
| **Name** | Fatima Ahmed |
| **Age** | 32 |
| **Occupation** | Marketing Manager |
| **Location** | Karachi, Pakistan |
| **Income** | PKR 120,000/month |
| **Tech Savviness** | Medium-High |
| **Device** | Samsung Galaxy S24, work laptop |

### Goals
- Find professional yet stylish workwear
- Shop efficiently without spending hours browsing
- Get reliable delivery for important occasions

### Frustrations
- Limited premium fashion options online
- Poor product photography that doesn't show true colors
- No express delivery options

### Behavior
- Shops online 2–3 times per month
- Willing to pay more for quality and convenience
- Uses credit card for online payments
- Values brand reputation and consistency
- Signs up for email newsletters for exclusive offers

### Quote
> "I don't mind paying premium — just make sure the experience matches the price."

## 4. Persona 3: Sara — The Business Owner (Admin)

| Attribute | Detail |
|-----------|--------|
| **Name** | Sara Malik |
| **Age** | 38 |
| **Occupation** | Afsheen Brand Operations Manager |
| **Location** | Islamabad, Pakistan |
| **Income** | Company-managed |
| **Tech Savviness** | Medium |
| **Device** | MacBook Air, iPad |

### Goals
- Manage product catalog efficiently
- Track orders and inventory in real-time
- Generate sales reports for business decisions

### Frustrations
- Manual order processing via WhatsApp is exhausting
- No centralized view of all orders and inventory
- Difficulty identifying top-selling products

### Behavior
- Checks dashboard multiple times daily
- Bulk-uploads products during new collection launches
- Monitors order statuses and resolves issues promptly
- Uses reports to plan restocking and promotions

### Quote
> "I need everything in one place — products, orders, customers, and revenue."

## 5. Persona 4: Hira — The Support Moderator

| Attribute | Detail |
|-----------|--------|
| **Name** | Hira Raza |
| **Age** | 26 |
| **Occupation** | Customer Support Specialist |
| **Location** | Remote |
| **Income** | PKR 45,000/month |
| **Tech Savviness** | Medium |
| **Device** | Desktop computer, smartphone |

### Goals
- Resolve customer queries as quickly as possible
- Access customer history to provide personalized support
- Manage multiple conversations efficiently

### Frustrations
- Losing context between different chat conversations
- No way to escalate issues to admin directly
- Repeated questions about order status that could be automated

### Behavior
- Handles 15–20 chat conversations daily
- Uses templates for common responses
- Escalates payment and refund issues to admin
- Flags recurring complaints for product team

### Quote
> "If I could see the customer's order history while chatting, I could solve issues in half the time."

## 6. Persona Comparison Matrix

| Feature Need | Ayesha | Fatima | Sara | Hira |
|-------------|--------|--------|------|------|
| Browse products | High | High | Low | Low |
| Size guide | Critical | High | Low | Low |
| Fast checkout | High | Critical | Low | Low |
| Order tracking | Medium | High | Critical | High |
| Admin dashboard | None | None | Critical | Low |
| Chat support | Medium | Low | Low | Critical |
| Mobile optimization | Critical | High | Medium | Low |
| Payment options | COD | Card/COD | All | All |

## 7. How Personas Inform Design

| Persona | Design Decision |
|---------|----------------|
| Ayesha | Mobile-first, fast loading, social sharing buttons |
| Fatima | Clean layout, premium aesthetics, express checkout |
| Sara | Dashboard with charts, bulk operations, real-time data |
| Hira | Chat interface with customer context, canned responses |
