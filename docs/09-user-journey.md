# 09 - User Journey

## 1. Purpose

This document maps the end-to-end journey of a customer using the Afsheen Premium Fashion Hub, from first visit to post-purchase support. It identifies key touchpoints, actions, emotions, and opportunities for improvement.

## 2. Customer Journey Map — Primary Flow

### Phase 1: Discovery & First Visit

| Step | User Action | System Response | Emotion |
|------|------------|----------------|---------|
| 1 | Clicks link from Instagram ad | Homepage loads with hero banner | Curious |
| 2 | Scrolls through featured products | Products display with images and prices | Interested |
| 3 | Clicks on a product category | Filtered product listing appears | Focused |
| 4 | Browses products, reads descriptions | Product cards show name, price, quick view | Engaged |

**Pain Point:** First-time visitors may not trust the site immediately.
**Opportunity:** Display trust badges, customer reviews, and return policy prominently.

### Phase 2: Product Exploration

| Step | User Action | System Response | Emotion |
|------|------------|----------------|---------|
| 5 | Clicks on a specific product | Product detail page loads with images, size guide, description | Interested |
| 6 | Views product images (zoom/rotate) | High-quality images from multiple angles | Confident |
| 7 | Checks size guide | Size chart modal/page opens with measurements | Reassured |
| 8 | Reads customer reviews | Reviews section shows ratings and comments | Trusting |
| 9 | Selects size and clicks "Add to Cart" | Item added to cart with confirmation animation | Satisfied |

**Pain Point:** Uncertainty about sizing.
**Opportunity:** Include a "Fit Finder" tool or customer photos in reviews.

### Phase 3: Cart & Checkout

| Step | User Action | System Response | Emotion |
|------|------------|----------------|---------|
| 10 | Opens cart, reviews items | Cart shows items, quantities, subtotal | Deciding |
| 11 | Applies coupon code | Discount applied, total updated | Happy |
| 12 | Clicks "Proceed to Checkout" | Multi-step checkout form appears | Determined |
| 13 | Fills shipping address | Address form with validation | Focused |
| 14 | Selects payment method (COD) | Payment option selected, order summary shown | Relieved |
| 15 | Clicks "Place Order" | Order confirmation page with order ID | Excited |

**Pain Point:** Complicated checkout causes abandonment (52% of users).
**Opportunity:** Guest checkout option, auto-fill address, progress indicator.

### Phase 4: Post-Purchase

| Step | User Action | System Response | Emotion |
|------|------------|----------------|---------|
| 16 | Receives order confirmation email | Email with order details and tracking link | Reassured |
| 17 | Checks order status | Order tracking page shows current status | Patient |
| 18 | Receives delivery notification | SMS/email with delivery date | Excited |
| 19 | Receives and inspects product | Product matches expectations | Satisfied |

**Pain Point:** Lack of real-time tracking updates.
**Opportunity:** Push notifications for status changes, live tracking map.

### Phase 5: Post-Purchase Engagement

| Step | User Action | System Response | Emotion |
|------|------------|----------------|---------|
| 20 | Opens chat to ask about exchange | Chat widget connects to moderator | Hopeful |
| 21 | Moderator resolves issue | Quick resolution with order context | Happy |
| 22 | Receives follow-up email | "How was your experience?" survey | Valued |
| 23 | Returns to shop for new collection | Personalized recommendations on homepage | Loyal |

## 4. Key Touchpoints

| Touchpoint | Channel | Purpose |
|-----------|---------|---------|
| Instagram Ad | Social Media | Drive traffic to homepage |
| Homepage | Web | First impression, navigation |
| Product Page | Web | Product details, decision making |
| Cart | Web | Review and modify selections |
| Checkout | Web | Payment and order placement |
| Confirmation Email | Email | Order confirmation and tracking |
| Order Tracking | Web | Real-time status updates |
| Chat Widget | Web | Customer support |
| Follow-up Email | Email | Feedback collection, re-engagement |

## 5. Cross-Platform Experience

| Platform | Experience |
|----------|-----------|
| Mobile (Primary) | Optimized layout, touch-friendly controls, fast loading |
| Desktop | Full-width layout, detailed product views, easy multitasking |
| Tablet | Hybrid layout adapting to orientation |

## 6. Opportunities for Improvement

| # | Opportunity | Impact | Effort |
|---|------------|--------|--------|
| 1 | Add product recommendations on homepage | High | Medium |
| 2 | Implement wishlist for later purchases | Medium | Low |
| 3 | Add social proof (recent purchases, reviews) | High | Low |
| 4 | Enable push notifications for order updates | High | Medium |
| 5 | Add a "Recently Viewed" section | Medium | Low |
| 6 | Implement exit-intent discount popup | High | Low |
